# radio-transmission — project gallery

Upload project-specific screenshots and photographs to this folder. Suggested filenames: `01-overview.webp`, `02-desktop.webp`, `03-mobile.webp`, `04-feature.webp`. Use optimized WebP or JPEG images; avoid huge originals.

Then edit `gallery.json` and add each image with an accurate descriptive `alt` text and optional caption. Example:

```json
{
  "images": [
    {
      "src": "01-overview.webp",
      "alt": "Project landing page showing the main navigation and dashboard overview",
      "caption": "Main interface"
    }
  ]
}
```

Only upload images you created or have permission to publish. Remove names, emails, phone numbers, account details, API keys, tokens, private dashboards and other sensitive data. Add third-party asset credits to `/credits.html`.
